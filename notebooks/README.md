# Training Notebooks
# ──────────────────

This directory is the expected location for the Colab training notebook.

## Required File

| File | Description |
|------|-------------|
| `offseg_improved.ipynb` | Full training pipeline — Colab T4 GPU verified |

## How to Obtain

The notebook is hosted on Google Colab:

🔗 [Open in Colab](https://colab.research.google.com/drive/1bhxIKapFMmfVzVD6uJ0sfkzPuuRTFM6a)

Download it (`File → Download .ipynb`) and place it here:

```
notebooks/
└── offseg_improved.ipynb
```

> **Note:** `.ipynb` files are excluded from Git via `.gitignore` to keep the
> repository lightweight. The Colab link above is the canonical source.
